В ОЖИДАНИИ ДРАКОНА — цифровая книга
===================================

Быстрый запуск без интернета:
1. Распакуйте архив в любую папку.
2. Откройте index.html в современном браузере (Chrome, Edge, Firefox, Safari).
3. Интернет не требуется: весь текст книги и интерфейс встроены в index.html.

Функции:
- минималистичный книжный интерфейс с режимом перелистывания;
- кнопки назад/далее, клавиши ←/→ и свайпы на телефоне;
- оглавление, поиск по всему тексту;
- прогресс чтения и локальное сохранение позиции;
- закладка, светлая/тёмная тема, настройки шрифта и интервала;
- печать / сохранение в PDF;
- manifest и service worker для офлайн-кэширования при запуске через localhost.

Важно про установку как PWA:
Браузеры не разрешают service worker и установку PWA при прямом открытии file://. При этом сама книга полноценно работает офлайн из index.html.
Если хотите активировать PWA-режим без интернета, можно запустить локальный сервер на компьютере:
  Windows: откройте папку книги, в адресной строке Проводника напишите cmd, затем выполните:
    py -m http.server 8000
  Откройте в браузере:
    http://localhost:8000
Первый запуск локального сервера не требует интернета. Для установки на телефон этот способ требует, чтобы телефон и компьютер были в одной локальной сети и чтобы сервер был доступен с телефона; установка на телефон через обычную ссылку обычно требует HTTPS.

Сохранность текста:
Текстовые строки исходного DOCX перенесены в книгу в исходном порядке без редакторской правки. Пустые абзацы сохранены в данных; оформление Word, изображения и разрывы страниц не переносились.
